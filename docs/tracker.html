Where we are

M3 in progress. Against held-out maps, the M3 policy (m3b) went from 3% to 44% wins vs baseline in about 150 updates, but scored only 6% vs relay and 0% vs balanced (both score ~11 per match).

A replay analysis showed why: relay's players average 11-13 u/s, above lethal speed over half the time, because they remember ground they have already crossed. Ours averaged about 6 u/s, lost every race, and died 13 times in collisions (the slower sphere dies).

Fix (features v2): each player now keeps a known-clear ground map, built from its own path, enemies it has seen, flag carriers and the home areas, with bumps marked as blocked. From the map it gets 8 body-relative ray distances plus a velocity ray, so the network can learn when sprinting is safe. Run m3c warm-starts from m3b via feature surgery: the new inputs start with zero weight, so the policy starts out identical to m3b.

Also new:
  • an optional GRU recurrent policy (built and tested; under review)
  • each training job now runs from its own frozen copy of the code
