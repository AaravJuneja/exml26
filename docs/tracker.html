Where we are

Steady progress. The best line (m4c: v4 features, 256×256, entropy 0.0001, λ 0.995, focused league curriculum) now beats, on held-out maps:
  • baseline 94-96%
  • guardian / rusher / camper ~48-56%, up from 15-35% earlier
  • relay ~6-15% and balanced ~8-17%, with goal difference narrowing to about -3
The review of the v5 migration found real risks, now fixed: policy files are never auto-migrated (strict loading), and lossy migrations are refused. A/B now: m5a (v5 memory features) vs m4c (v4). In progress: releasing m4c's best snapshot as teams/exml_rl via the full release pipeline.
